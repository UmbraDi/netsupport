# netsupport

Программа для мониторинга сетевых узлов и диагностики соединений у абонентов.

## Описание
Программа проверяет доступность узлов (ping), сохраняет историю и присылает уведомления о проблемах. Может найти порт абонента по маку, проверить ошибки, скорость и прочую необходимую информацию.

## Технологии
- Java 25
- Maven
- Hibernate
- Telegram Bot API
- PostgreSQL
